# Анкета: формат огляду ситуації з безпекою

Публічна сторінка для збору зворотного зв'язку від клієнтів SK Security
щодо формату щотижневого огляду ситуації з безпекою.

Клієнтам надсилаються два варіанти огляду за один період:

* **Формат А** — розгорнутий текстовий (понад 20 тематичних розділів, без графіки);
* **Формат Б** — структурований візуальний (таблиці, графіки, карта, матриця рекомендацій).

Формати подано знеособлено, без зазначення авторів, щоб не впливати на відповіді.

## Обсяг анкети

Свідомо обмежений двома речами: **вибором формату** та **оцінкою корисності розділів**
(слайдер 0–10 на кожен розділ, включно з тими, яких в огляді поки немає).
Питання про періодичність, канали термінових сповіщень і практику ухвалення рішень
прибрані: періодичність визначена договором, а решта виходить за межі того,
що анкета має вирішувати.

Обов'язкове питання одне — вибір формату. Компанія обирається перемикачем
(«Марс Україна» / «Рояль Канін Україна»), за замовчуванням — «Марс Україна».

## Технічно

* Один статичний файл `index.html`, без залежностей і збірки.
* Відповіді надсилаються у [Formspree](https://formspree.io/) (`/f/xppwogbo`)
  через `fetch` з `Accept: application/json`, тому сторінка не перезавантажується.
* Сторінка закрита від індексації (`noindex, nofollow`).
* Захист від спаму — приховане поле `_gotcha`.

## Публікація

GitHub Pages, гілка `main`, корінь репозиторію.

## Зміна адреси прийому відповідей

Замінити значення `action` у формі та посилання в цьому файлі.
